Configuración del Sistema

Administra los usuarios, roles, autenticación y accesos del sistema.

Usuarios

Gestiona la creación, edición y eliminación de usuarios del sistema.

Roles

Define y asigna permisos a los distintos roles de usuarios.

Autenticación

Configura los métodos de autenticación como local, Active Directory y otros.

Menús

Organiza las opciones del menú disponibles en la aplicación.

Accesos

Controla qué roles tienen acceso a qué funcionalidades o menús.
